## 📖 نظرة عامة (Overview)

**Aqua Pivot Calc PRO** هو تطبيق هندسي احترافي مصمم خصيصاً لمهندسي الري، والمزارعين، والمشرفين الفنيين لإدارة وتصميم وحساب كافة المعطيات الهندسية، الهيدروليكية، والتشغيلية لأجهزة الري المحوري بدقة فائقة وبمعايير هندسية معتمدة عالمياً (Valley, Zimmatic, Reinke, Bauer).

---

## ✨ المميزات الرئيسية (Key Features)

### 1. 📐 المواصفات الهندسية ومساحات الحلقات والأبراج
* **المعايير المعتمدة**: دعم معيار الفدان المصري (4200.83 م²) والفدان السوداني (4200.00 م²).
* **التفقيط الهندسي المعتمد**: تفقيط تلقائي دقيق للمساحات (فدان · قيراط · سهم · هكتار · متر مربع).
* **حسابات الهيكل والأبراج**:
  * أطوال الأسبانات والأبراج المنفردة أو الموحدة.
  * حساب نصف قطر وطول ماسورة الهيكل ونصف قطر البلل الكلي.
  * حساب مساحة ونسبة كل برج من إجمالي الحقل.
  * حساب مساحة الكابولي المعلق (Overhang) ونطاق مدفع النهاية (End Gun).

### 2. 🎯 المخطط الراداري التفاعلي (2D Visualizer)
* محاكاة بصرية تفاعلية ثنائية الأبعاد (2D Radar) لهيكل المحور، الأبراج، وأبراج الدوران في الوقت الفعلي.
* عرض مسارات الإطارات، ونطاق البلل، والكابولي بلمسة احترافية.

### 3. 💧 الحسابات الهيدروليكية والتشغيل الزراعي
* **نمطين للحساب**:
  1. حساب التدفق المطلوب بناءً على عمق الري المستهدف (مم/يوم).
  2. حساب عمق الري المتاح بناءً على تصريف المضخة/البئر الفعلي (م³/ساعة).
* **المقررات المائية للمحاصيل والمناخ**:
  * قاعدة بيانات مدمجة لاحتياجات المحاصيل (القمح، الذرة، البرسيم، البطاطس، الشعير، الصويا، الأعلاف).
  * حساب البخر نتح المرجعي (ETo) ومعامل المحصول (Kc) وفق الظروف المناخية ودرجات الحرارة.
* **الحسابات التشغيلية والسرعة**:
  * زمن الدورة الكاملة (360°) عند نسبة تايمر 100% والزمن الفعلي عند أي نسبة مضبوطة.
  * سرعة البرج الأخير الفعلية (م/ساعة) ومحيط مسار العجلات.
  * عمق مياه الري المطبق في اللفة الواحدة (Gross Applied Depth - ملم/لفة).
  * **دليل التايمر وأعماق الري (Timer vs Depth Guide)**: جدول تشغيلي ميداني فوري لأعماق الري وأزمنة الدوران عند مختلف نسب التايمر (من 100% إلى 10%).

### 4. ⚙️ حاسبة وبرمجة فوهات البخاخات (Nozzle Sizing & Chart)
* **الموديلات المعتمدة عالمياً**:
  * نيلسون D3000 Sprayhead (Nelson)
  * نيلسون روتاتور R3000 Rotator
  * نيلسون أوربيتور هلال Orbitor
  * هنتر سوبر سبراي UP3 (Hunter)
  * سيننجر آي ووب i-Wob UP3 (Senninger)
* **برمجة الفوهات الدقيقة**:
  * حساب تصريف كل بخاخ (GPM و لتر/دقيقة).
  * تحديد رقم الفونية الدقيق (#)، قطر الفتحة بالمليمتر والبوصة، واللون المعتمد مع كود اللون الفعلي.
  * ضغوط المنظمات القياسية (6, 10, 15, 20, 30 PSI).
  * استاندرات التباعد المعتمدة: القياسي (108")، المكثف (72")، الفائق LEPA (40").

### 5. 🛡️ لوحة تحكم المشرف المعتمد (muzamil)
* **حماية الملكية الهندسية**: إظهار معاينة تجريبية فقط للعملاء وحجب الجدول الكامل لحين اعتماد المشرف.
* **إدارة طلبات المزارعين الواردة**:
  * استقبال مواصفات وأبعاد محاور العملاء تلقائياً.
  * أزرار اتصال مباشر ومراسلة عبر واتساب بنقرة واحدة.
  * زر تحميل المعطيات مباشرة إلى الحاسبة للمراجعة والاعتماد.
* **جدول الفوهات المعتمد للمشرف**:
  * شاشة وتصدير خاص لجدول الفوهات الكامل 100% لجميع البخاخات.
  * جدول حصر وتجميع كميات الفونيات المطلوبة للتوريد (Bill of Materials - BOM).

### 6. 📄 التقارير الهندسية والطباعة (PDF & Sharing)
* **تقرير الهيدر المختصر**: تقرير رسمي معتمد للمواصفات الهندسية وتقرير الري والتشغيل ودليل التايمر دون إفشاء جدول الفونيات التفصيلي.
* **ملف وجدول الفوهات المعتمد (خاص بالمشرف)**: ملف تفصيلي كامل بجميع فوهات الرشاشات وجدول التوريد وختم وتوقيع المشرف (muzamil).
* ميزة الطباعة المباشرة عبر الطابعة أو الحفظ والمشاركة بصيغة PDF عالية الدقة متوافقة مع صفحات A4.

## 🚀 بدء التشغيل والتشغيل المحلي (Getting Started)

### المتطلبات المسبقة:
* تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث).
* تطبيق [Expo Go](https://expo.dev/go) على هاتفك الجوال لمعاينة التطبيق مباشرة.

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the repository)**:
   ```bash
   git clone https://github.com/Arabialzol/pivot-irrigation-expo.git
   cd pivot-irrigation-expo
   ```

2. **تثبيت الحزم البرمجية (Install dependencies)**:
   ```bash
   npm install
   ```

3. **تشغيل سيرفر التطوير (Start development server)**:
   ```bash
   npx expo start -c
   ```
   * امسح رمز الـ **QR Code** الظاهر بواسطة تطبيق **Expo Go** على هاتفك الأندرويد أو الآيفون لتشغيل التطبيق فوراً.
